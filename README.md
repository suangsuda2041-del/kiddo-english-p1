# 🎒 Kiddo English ป.1 - เว็บแอปพลิเคชันสื่อการสอนภาษาอังกฤษ ป.1

เว็บแอปพลิเคชันสื่อการสอนภาษาอังกฤษสำหรับนักเรียนชั้นประถมศึกษาปีที่ 1 (ป.1) ออกแบบตามหลักสูตรแกนกลางกลุ่มสาระการเรียนรู้ภาษาต่างประเทศ (สพฐ.) เพื่อการเรียนรู้ที่สนุกสนาน มีชีวิตชีวา และกระตุ้นการมีส่วนร่วมของเด็กๆ

---

## 🌟 จุดเด่นและฟังก์ชันการใช้งาน

### 1. 🔤 พยัญชนะและโฟนิกส์ (Alphabet & Phonics A - Z)
- ครบถ้วนทั้ง 26 ตัวอักษร (Aa - Zz) พร้อมเสียงโฟนิกส์ เช่น `A says /æ/ (แอะ) ... Apple`
- มีปุ่มแยกหมวด **สระ (A, E, I, O, U)** และ **พยัญชนะ**
- กดฟังเสียงอ่านภาษาอังกฤษชัดเจนจากเจ้าของภาษา (Native English Speech) ผ่าน Web Speech API
- กดที่การ์ดเพื่อเปิดดูหน้าต่างขยายใหญ่ (Big Card Modal) พร้อมรูปภาพประกอบ คำแปลไทย และประโยคตัวอย่าง

### 2. 📚 คำศัพท์พื้นฐาน ป.1 (6 หมวดหมู่สำคัญ)
- **🔢 ตัวเลข (Numbers 1-10):** พร้อมจุดนับจำนวนตามตัวเลข
- **🎨 สีสัน (Colors):** พร้อมแถบสีจริงช่วยจำ (Red, Blue, Yellow, Green, etc.)
- **🐶 สัตว์แสนรัก (Animals):** เสียงร้องสัตว์และคำศัพท์ยอดนิยม
- **🍎 ผลไม้และอาหาร (Fruits & Food):** Apple, Banana, Milk, Bread, Egg, etc.
- **🧍 ร่างกายของฉัน (My Body):** Head, Eye, Ear, Nose, Hand, Leg, etc.
- **🏫 โรงเรียนและคำทักทาย (School & Greetings):** Book, Pencil, Desk, Hello, Good morning, Thank you

### 3. 🎮 3 มินิเกมฝึกทักษะแสนสนุก (Interactive Mini-Games)
1. **👂 ฟังเสียงแล้วทายภาพ (Listen & Pick):** ฝึกทักษะการฟัง (Listening Skill) กดฟังเสียงแล้วแตะภาพที่ถูกต้อง 1 ใน 4 ตัวเลือก พร้อมคะแนนและดาว
2. **🃏 เปิดป้ายจับคู่ (Memory Match):** การ์ด 3D พลิกได้ จับคู่ภาพกับคำศัพท์ภาษาอังกฤษ ฝึกความจำและสมาธิ
3. **🐝 ผึ้งน้อยสะกดคำ (Spelling Bee):** คำศัพท์ง่าย 3-4 ตัวอักษร (เช่น CAT, DOG, SUN, HAT) แตะลูกโป่งตัวอักษรเพื่อสะกดคำ พร้อมเสียงออกเสียงทีละตัว

### 4. ⭐ ระบบรางวัลและ Gamification (Star & Sticker Rewards)
- สะสมดาว ⭐ ทุกครั้งที่ฝึกอ่านและเล่นเกมชนะ
- มีพลุสายรุ้ง (Canvas Confetti) และเสียงเอฟเฟกต์ฉลองเมื่อผ่านด่าน
- **สมุดสะสมสติกเกอร์ (Sticker Book):** ปลดล็อกเหรียญตราเกียรติยศเมื่อสะสมดาวถึงเป้าหมาย
- บันทึกคะแนนและดาวลงในเบราว์เซอร์อัตโนมัติ (LocalStorage) ไม่ต้องกังวลว่ารีเฟรชแล้วข้อมูลจะหาย

### 5. 👨‍🏫 เครื่องมืออำนวยความสะดวกสำหรับคุณครูและผู้ปกครอง
- **🐢 ปุ่มสลับเสียงอ่านช้า (Slow Speech Mode):** ปรับความเร็วเสียงพูดให้อ่านช้าและชัดขึ้น สำหรับเด็กที่เพิ่งเริ่มหัดออกเสียง
- **🖥️ โหมดเต็มจอ (Fullscreen Mode):** กดปุ่มเดียวเพื่อขยายเต็มจอสำหรับฉายบนโปรเจกเตอร์หรือสมาร์ททีวีในห้องเรียน
- **🔊/🔇 เปิด-ปิดเสียงเอฟเฟกต์:** ปรับแต่งเสียงได้ตามความเหมาะสมของสภาพแวดล้อมห้องเรียน
- **100% Client-Side:** ไม่ต้องติดตั้งโปรแกรมหรือ Node.js ใดๆ สามารถดับเบิลคลิกเปิดใช้งานได้ทันที

## 🚀 วิธีเปิดใช้งาน

1. ไปที่โฟลเดอร์ `c:\สื่อการสอนอิ้ง`
2. ดับเบิลคลิกที่ไฟล์ **`index.html`** เพื่อเปิดในเบราว์เซอร์ใดก็ได้ เช่น **Google Chrome**, **Microsoft Edge**, **Safari**, หรือ **Firefox**
3. สามารถใช้งานได้ทั้งบนคอมพิวเตอร์ตั้งโต๊ะ, โน้ตบุ๊ก, แท็บเล็ต (iPad/Android) และสมาร์ทโฟน
